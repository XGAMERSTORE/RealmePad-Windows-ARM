# Realme Pad variants

- RMP2102: Wi-Fi and LTE.
- RMP2103: Wi-Fi only.
- Shared RMP6768 board family and Helio G80.

Both variants are research targets. LTE requires additional modem, SIM and cellular driver support. Wi-Fi requires its own wireless driver. Neither variant has working Windows UEFI or Windows drivers yet. The existing TWRP checker only reports Android properties; it does not install Windows or enable LTE. Never flash unverified firmware.
